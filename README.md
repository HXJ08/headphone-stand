# Headphone Stand

A parametric 3D printed headphone stand designed in Fusion 360. Features a curved hook, weighted base, and cable management clip.

## What it does

- Holds headphones on a desk with a stable base
- Curved hook distributes weight evenly
- Weighted base prevents tipping
- Cable management clip on the back

## Dimensions

- **Base:** 120mm diameter, 8mm thick
- **Height:** 280mm total
- **Hook curve:** 60mm radius arc
- **Material:** PLA, 20% infill, 3 walls

## CAD Design

Designed in Fusion 360 with parametric dimensions. Key features:

- **Base:** Cylinder with a chamfered edge and a recess for a steel weight plate
- **Stem:** Tapered cylinder from base to hook
- **Hook:** Swept arc with a rounded profile
- **Cable clip:** Small protrusion on the back of the stem

All dimensions are parametric, so the stand can be resized for different headphone sizes.

## 3D Printing

- **Orientation:** Base down, hook up
- **Supports:** Only under the hook overhang
- **Infill:** 20% gyroid
- **Walls:** 3
- **Material:** PLA
- **Print time:** ~6 hours
- **Filament:** ~80g
